# OnboardAI - Checklist hội nhập

## Mục đích
Trang web mẫu giúp nhân sự mới theo dõi các nhiệm vụ hội nhập, trạng thái hoàn thành và tiến độ.

## Công nghệ
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript thuần
- localStorage để lưu trạng thái nhiệm vụ trên trình duyệt

## Chức năng
- Đánh dấu hoàn thành/chưa hoàn thành.
- Tự động tính phần trăm tiến độ.
- Lọc tất cả, chưa hoàn thành, đã hoàn thành.
- Tìm kiếm nhiệm vụ.
- Giao diện responsive cho desktop và mobile.
- Lưu trạng thái nhiệm vụ trên cùng trình duyệt bằng localStorage.
- Trợ lý AI là nội dung mô phỏng, không gọi AI API thật.

## Cách chạy
Mở `index.html` bằng trình duyệt. Nếu trình duyệt chặn một số tính năng cục bộ, hãy chạy thư mục bằng extension Live Server trong VS Code.

## Cấu trúc
- `index.html`: cấu trúc trang
- `css/style.css`: kiểu dáng và responsive
- `js/main.js`: dữ liệu mẫu và tương tác
